# LMS 데이터베이스 연관관계 설명: Core의 물리적 위치

ERD 다이어그램에서 `Core`가 `Space`를 통해 `Enclosure`에 연결되는 것처럼 보이는 것은, 데이터베이스가 물리 세계의 포함 관계를 논리적으로 표현하기 때문입니다. `Core`는 직접적으로 `Space`에 연결되지 않지만, 여러 단계를 거쳐 자신의 물리적 위치 정보(`Space`)를 찾아갈 수 있습니다.

이 연관관계는 다음과 같은 흐름으로 이루어집니다.

### 1. `Core` → `Port` : 신호의 시작과 끝

- **`Core`**는 광케이블 내의 **하나의 광섬유 가닥**으로, 신호가 흐르는 최소 단위입니다.
- 이 신호는 반드시 장비의 특정 **`Port`**에서 시작하고 끝나야 합니다.
- `cores` 테이블의 `from_port_id`와 `to_port_id` 컬럼이 이 관계를 나타내며, 특정 `Core`가 어떤 `Port`에 연결되어 있는지를 명시합니다.

### 2. `Port` → `Switch` : 포트의 소속

- **`Port`**는 독립적으로 존재할 수 없으며, 항상 특정 **`Switch`** 장비에 속해 있습니다.
- `ports` 테이블의 `switch_id` 컬럼이 이 관계를 나타내며, 해당 `Port`가 어떤 `Switch`에 속한 것인지를 명시합니다.

### 3. `Switch` → `Enclosure` : 장비의 설치 위치 (함체)

- **`Switch`** 장비는 물리적으로 **`Enclosure`(함체)** 내부에 설치됩니다.
- `switches` 테이블의 `enclosure_id` 컬럼이 이 관계를 나타내며, 해당 `Switch`가 어떤 `Enclosure` 내에 위치하는지를 명시합니다.

### 4. `Enclosure` → `Space` : 함체의 설치 위치 (공간)

- 마지막으로, **`Enclosure`**는 'MDF실', '통신실'과 같은 특정 **`Space`(공간)** 안에 위치합니다.
- `enclosures` 테이블의 `space_id` 컬럼이 이 관계를 나타내며, 해당 `Enclosure`가 어떤 `Space`에 설치되었는지를 명시합니다.

---

## 결론

이처럼 **`Core` → `Port` → `Switch` → `Enclosure` → `Space`** 로 이어지는 연관관계를 통해, 우리는 가장 작은 단위인 광섬유 한 가닥(`core`)이 최종적으로 어느 건물, 어느 층, 어느 공간(`space`)의 어떤 함체(`enclosure`)에 있는 어떤 스위치(`switch`)의 몇 번 포트(`port`)에 연결되어 있는지 전체 경로를 완벽하게 추적할 수 있습니다.

다이어그램에 표시된 선들은 바로 이 논리적인 포함 관계와 연결을 시각적으로 보여주는 것입니다.
